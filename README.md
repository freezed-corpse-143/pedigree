# Pedigree Tree Layout

A design-first project for generating report-quality pedigree trees from a directed acyclic graph (DAG). The root is placed at the bottom of an SVG canvas; structural branches grow upward and adapt to the graph while decorative twigs add visual detail without changing graph semantics.

Implementation has not started. Current work defines and validates requirements and architecture first.
