# 独占枝轴：一个展开子树

- 日期：2026-10-17
- 状态：保留为不漂移基线；后续 [A/B 几何验证](clearance.md) 已完成，不代表最终树形。
- [设计](../design/stem-owned.md) · [生成图](../../output/one-subtree-D.svg)。

## 生成

```sh
bun run generate
bun tests/stem.test.ts
```

输出 `output/one-subtree-D.svg`，内容确定、可重复生成。

- `src/layout/`：`layoutStemScene(initialized, layoutConfig)`，只返回每个人的 `{id, center, from, to, angle}`；`phase` 状态与规范化树由 `src/state.ts` 提供。
- `src/generate-one-subtree.ts`：只调用 `run()`；输入固定为 `data/one-subtree.json`，写出前由 `tests/pipeline.test.ts` 与实验断言相框最小间距。
- `tests/stem.test.ts`：逐项断言枝轴独占、分叉位置、倾角上限、相框避让、递归侧别、排序、平局回弯和非法输入。

## 输入

根 `n0` 有一个展开的子枝 `n1`（`n1` 下有 `n2`、`n3`），另有叶子 `n4`、`n5`。相框 48 × 42，间距 12。

## 结果

- 几何范围四舍五入为 344 × 437，实际 SVG width/height 向上取整为 345 × 437；6 个相框零重叠，最小轴向间距 23.90。
- 根层 `n4`、`n5` 同处右侧，`n1` 独占左侧。
- 在 `n1` 这条子枝上，`n2` 回弯到垂直（相对 `n1` 的 -32°），`n3` 位于外侧（+32°，绝对 64°）；两者分居两侧。
- 根轴质量偏移 0.503。

## 可直接观察的结构

- 每个节点都有自己的分叉点、笔直枝轴和高于最高分叉的冒尖末端；没有子节点直接立在父节点正上方。
- 子枝轴与父枝轴的夹角为 32°，不为零；所有人物向上生长。
- 相框保持水平，间距使用旋转不变的中心距，旋转后仍不重叠。

## 参数与限制

- 本基线仍使用倾角 32°、绝对倾角上限 70°、接入 80、冒尖至少 44、扫描步长 6；B 在其他失败输入上才延长接入，基线图未变。
- 本图只覆盖一个展开子树；多层树验证和剩余限制见 [A/B 结果](clearance.md)。
- 现有直枝带有简单收细；自然枝条造型、树皮、挂接、真实姓名/长文本、叶片未实现。
- 间距门槛是保守值，实测最小间距 23.90，而不是刚好 12；这是为了避免“局部满足、旋转后失效”。
