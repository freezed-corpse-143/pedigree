# 自然树谱系图：目标与分阶段验收

- 日期：2026-10-17
- 状态：探索目标已由用户授权；具体算法尚未定案。
- 用户目标：给定一棵树，绘制一棵像自然界树木一样的谱系图；拆分难度逐步设计，由工程侧探索路线，不要求用户预选算法或参数。
- 本轮交付：新需求、设计、一个可复现的独占枝轴示例与结论；不是最终应用或最终艺术效果。

## 1. 视觉依据

- 完整树参考（本地图，不纳入版本控制）：根部在下，主干连续，分枝粗细递减，冠形不完全对称，人物沿主轴和支轴分布。
- 局部参考（本地图，不纳入版本控制）：弯曲、收细的枝条，挂接式相框，少量装饰细枝和叶片。
- 从图像只能观察外观，不能可靠反推出每个人的父子关系。实验不把参考图中的人名猜测成数据集。
- 相似目标是树体结构与人物可读性，不复制图片、纹理或原作人物资产。

## 2. 数据边界

当前用户输入是一棵有根树：节点 ID 唯一，每个非根节点恰有一个父节点，所有节点从根可达，无环。不自行扩展为多人婚配、共享子女的 DAG，也不把这种数据静默复制成树。那些是后续独立需求，不是已取消的能力承诺。

节点代表人物；结构边代表输入中的父子关系。树干延续是一条真实父子边的几何选择，不意味着被选择的人更重要。装饰枝不能伪造关系。

兄弟数组顺序默认仅用于确定性打破平局，不等同出生顺序。若以后提供长幼/时间约束，必须成为明确的数据字段和硬约束，不能假装本轮已支持。

## 3. 最终结果的验收目标

1. 所有人物与父子边完整保留，关系可追踪，没有虚构或重复人物。
2. 根在下，主体总体向上生长；存在连续主干、自然分叉和收细枝梢，而不是等宽折线或梯形板。
3. 人物相框和文字不互相覆盖，非关联树枝不能遮挡人物信息。
4. 不以强制左右人数相等替代视觉平衡；单侧大子树不应被压缩到不可读。
5. 允许不对称；不能为了居中破坏关系、顺序约束、间距。
6. 同一输入产生同一结果；未来若采用随机扰动，必须固定种子且不影响正确性。
7. 不固定小画布硬塞任意数据；优先自然尺寸和缩放，超大树的折叠/分页另行设计。
8. 装饰必须从属于已通过可读性验收的结构，不靠叶片遮住布局缺陷。

上述是目标，不是本轮完成声明。量化指标不能独立证明“自然”。

## 4. 逐级增加难度

| 阶段 | 只增加的问题 | 验收证据 |
|---|---|---|
| S0 | 单主轴、单节点、链 | 人物/边完整、方向正确、主轴连续 |
| S1 | 一个父节点、等大叶子 | 分边与排序规则明确；相框不重叠 |
| S2 | 不等规模的子树递归 | 链、宽扇、平衡、偏斜、梳状、混合输入；报告交叉/遮挡/占用范围 |
| S3 | 选定路线的空间修正 | 解决 S2 暴露的首个具体冲突；不增加装饰掩盖它 |
| S4 | 自然枝条与挂接相框 | 平滑接续、收细、标签避让；近看与全树截图 |
| S5 | 少量叶片/细枝与真实内容 | 不新增结构语义；重新检查可读性 |

六节点独占枝轴示例保留为不漂移基线；S3 已继续完成 [A/B 几何可读性验证](../experiments/clearance.md)：框—框、枝—框、枝—枝及父轴延长完整检查，无解时仅增加接入长度候选。多层满二叉树、链、扇、梳状、偏斜和多个展开子树通过本轮检查；“混合”族（宽扇 + 深链 + 小子树）曾显式拒绝，现由祖先轴走廊预留解决；冻结 200 棵树全部出图，代价是画布增大 10–15%。任意规模完备性、角度上限处两侧退化和更紧轮廓仍未解决。S4 已开始（渲染层：自包含配色、框内标签适配、分叉盖缝、光滑收细），枝条曲线与挂接式相框未做；S5 未开始。

后续 [S 有限换侧](../experiments/side-search.md) 在同一 200 输入语料上将接受数从 150 提至 160，原成功图不漂移；仍有 40 个拒绝，首个 9 节点父轴受阻反例未解决。不得将这些局部成功标记为任意树完整支持。

结构规则（用户 2026-10-17 修正，2026-10-20 补充）：每个节点必须独占一段笔直枝轴并向上冒尖；子节点从父枝轴上的分叉点生长；有多个子节点时任何子节点都不得与父枝轴共线，**只有一个子节点时该子节点延续父轴（共线、不偏转）**，父枝轴在它的分叉点结束。该规则由 [ADR 0002](../decisions/0002-owned-stems.md) 记录，并在[单例结果](../experiments/stem.md) 中验证；它替代“某个子节点延续父轴”的旧结构假设，但不代表整棵自然树已完成。

## 5. 优先级与非目标

硬约束：数据正确、有限坐标、确定性、人物可读。软目标：少交叉、空间紧凑、视觉平衡、自然姿态。最终非关联结构边的交叉仍应消除；筛选实验允许失败并如实记录。

本轮不实现编辑器、导入 UI、照片管理、动画、物理仿真、全局最优化器、冠形模板库或新的前端框架。
