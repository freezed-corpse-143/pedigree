# Architecture Decision Records

ADRs capture durable choices where alternatives and consequences matter. Number records sequentially and never rewrite an accepted decision to hide history; supersede it with a new ADR.

| ADR | Status | Decision |

## ADR lifecycle

`Proposed → Accepted → Superseded`

A design may reference a proposed ADR during review. Implementation planning requires every referenced ADR to be accepted or explicitly marked as a time-boxed experiment.
