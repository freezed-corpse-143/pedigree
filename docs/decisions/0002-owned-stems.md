# ADR 0002：每个节点独占笔直枝轴，子节点从分叉点生长

- 日期：2026-10-17
- 状态：接受为下一轮结构探索的基础；不代表整体自然树方案已定案。
- 依据：[独占枝轴设计](../design/stem-owned.md)、[首轮结果](../experiments/stem.md)。

## 背景

旧 C/S 模型用父框到子框的射线表示关系。单子节点会继承父轴，奇数分叉的中间子节点也可能与父轴共线；结果父节点上方马上出现子节点，父节点没有属于自己的树干。用户明确指出主树干应独占并冒尖，子树枝应笔直，子根节点也应独占并冒尖，然后递归。

## 决定

1. 每个节点独占一条笔直枝轴：父枝轴上的分叉点 → 本节点相框 → 自由末端；相框以上的部分是其冒出部分。
2. 子节点从父枝轴上的分叉点生长；先按子树规模降序处理（输入顺序破平局），再搜索分叉高度。重枝先处理，但碰撞搜索不保证重枝最终更低；父枝轴越过最高分叉至少 44。
3. 任何子节点的枝轴方向都不得与父枝轴共线；首轮使用 ±32°。左右侧别按子树规模配平（轻侧优先），若会让绝对倾角超过 70°，则翻到另一侧，保证所有人物仍向上生长；70° 允许父枝已偏 32° 时两个等量子节点仍分居两侧。负荷平局时优先回弯到更接近垂直的一侧，两侧角相等时按深度交替，避免单链逐级漂过轴。
4. 子相框中心沿接入枝与分叉点优先保持 80 单位距离。2026-10-18 的 [A/B 设计](../design/geometry-clearance.md) 保留结构，仅在完整几何判定无法安放时延长接入；角度和子树内部结构不变。
5. 相框保持水平。间距使用旋转不变的中心距 `hypot(w+gap, h+gap)`，因为局部轴对齐间距在旋转后不成立；首轮因此实测最小轴向间距为 23.9，而非 12。
6. 六节点图保留为不漂移基线；已增加多层几何验证，但仍不宣称生产应用或任意树完备布局。
7. 后续 [S 设计](../design/side-search.md) 只允许首选侧无法安放后有限换侧：角度仍为 ±32°，最多 32 次全树共享备用侧尝试，成功才计入侧负荷。不改变原已成功布局；不宣称解决全部父轴增长冲突。

## 修订 2026-10-20：独子延续父轴

用户反馈：根节点之后只有一个第一级子节点时，按自然树常识应共线、不偏转。第 3 条因此改为：

- **恰好一个子节点**时，该子节点继承父轴方向（相对角 0°），父枝轴在该分叉点结束，不再向上冒尖；父子两段等宽相接，拼成连续主干。
- **两个及以上子节点**时规则不变：±32°、70° 上限、侧别配平；任何子节点仍不得与父枝轴共线。
- 共线只允许“端到端相接”（子枝起点 = 父枝终点）。共线但中段重叠仍是 `branch-branch` 冲突。
- 走廊预留对延续段不生效：该父轴不会再有兄弟需要扫过。
- 开关 `layout.continueSoleChild`，默认 `true`；历史 A/B 与侧别实验显式设为 `false`，以保证存档证据可复现。

代价（实测，冻结 200 棵树）：`axisMoment` p50 0.513 → 0.344、`branchMoment` p50 0.513→0.533（p95 0.845→0.778）、基础接入占比 0.911 → 0.961（更少拉长），但树更瘦高：aspect p95 2.208 → 3.365、max 2.673 → 7.552，height max 1396.7 → 1499.1。形状门槛已按流程重新冻结，理由见[验收指标](../design/acceptance-metrics.md#6-重新冻结独子延续父轴2026-10-20)。

## 被拒绝的替代

- **让主子树延续父轴（多子树时选一枝）**：违背“父节点独占冒尖”，且要在兄弟间选“主干”，会让某个孩子凌驾于其它孩子之上。2026-10-20 的修订只允许“恰好一个孩子”时延续，此时不存在选择，也不产生跨代共享枝轴。
- **所有子节点仍在父节点中心分叉**：父节点没有独立分叉区间，树干仍被子节点共享。
- **共享一条跨代主干**：更像真实树的领导枝，但节点无法“独占”枝轴，且与用户明确要求冲突。
- **只在父框上方加装饰短桩**：不能保证子节点不共线，也不改变连接结构。
- **局部包围盒间距**：首轮实验已证明旋转后最小间距跌到 3.79 并出现穿框，故弃用。

## 后果

- 解决了子节点直接位于父节点上方的结构问题；保留示例中 6 个相框零重叠、最小轴向间距 23.90。
- 树更高、单链更宽；父枝轴的分叉逐级堆叠，可能产生高而窄的树。
- 固定参数尚未调优；间距是保守值；枝轴艺术与真实标签未实现。
- 下一步只调整一个结构参数并复测，不并入占用盒或任意递归优化，直到树高与偏斜的代价被接受。
