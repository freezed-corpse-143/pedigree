# Implementation Plans

Implementation plans are written only after the associated requirements, design, and architecture decisions are approved.

Each plan must include:

- links to its approved requirement and design documents;
- exact files to create or modify;
- small test-first steps;
- commands and expected failure/pass evidence;
- migration and compatibility work, if any;
- documentation and changelog updates;
- a final smoke scenario exercising the rendered output.

Plans use the filename `YYYY-MM-DD-<feature>.md`. A plan is execution guidance, not a substitute for design review.
